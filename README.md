# Hafisa Magezi Foundation

Multi-page site for the Hafisa Magezi Foundation — inspiring hope, growing futures across Uganda.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home
- `/about` — Story, journey, partners, voices
- `/programs` — Education, agriculture, community
- `/contact` — Reach us

## Stack

- Next.js (App Router)
- Tailwind CSS
- Framer Motion
- Cormorant Garamond + Manrope

Copy, stats, and imagery paths live in `lib/content.ts`.

## Imagery

The site uses **custom Uganda-inspired artwork** created for Hafisa Magezi Foundation plus **authentic launch photography** from Masaka. No stock template photography.
